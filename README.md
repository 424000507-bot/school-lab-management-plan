# Secure and Sustainable School Computer Laboratory Management Plan

This repository contains a comprehensive management strategy for a school computer laboratory consisting of 30 desktop workstations and 1 web server. The project focuses on improving cybersecurity, automating routine IT administration tasks, reducing technical personnel workload, and minimizing electronic waste.

## Repository Structure
school-lab-management-plan/
├── scripts/
│   └── sys_info.ps1          # Task 1: PowerShell script for system & storage diagnostics
├── firewall/
│   └── firewall_rules.md     # Task 2: Firewall rule matrix and network security policy
├── lifecycle/
│   └── lifecycle_plan.md     # Task 3: Sustainable IT lifecycle management & e-waste plan
├── synthesis/
│   ├── synthesis.md          # Task 4: Integration synthesis write-up
│   └── guide_questions.md    # Group answers to core scenario guide questions
└── docs/
├── roles_assignment.md   # Member roles and responsibility matrix (Group of 8)
└── screenshots/          # Execution proof and output captures


## Summary of Objectives & Tasks
1. **Task 1: Bash/PowerShell Scripting** - Automated system identity, OS, and disk utilization diagnostic collector.
2. **Task 2: Firewall Rule Design** - Principle of Least Privilege filtering matrix protecting web server resources and internal workstations.
3. **Task 3: Sustainable IT Lifecycle** - Preventive maintenance, hardware upgrade prioritization (SSDs/RAM), Linux repurposing, and NIST 800-88 compliant e-waste handling.
4. **Task 4: Synthesis & Integration** - Multi-disciplinary write-up connecting automation, network protection, and eco-friendly IT sustainability.
