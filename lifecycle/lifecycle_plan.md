# Task 3: Sustainable IT Lifecycle Management Plan

## 1. Routine Maintenance & Security Updates
* **Automated Patch Management:** Deploy scripts to push OS security updates bi-weekly during off-peak hours.
* **Physical Hardware Hygiene:** Perform quarterly physical cleaning (dust blower cleaning, thermal paste refresh) to prevent overheating.
* **Storage Maintenance:** Run automated disk cleanup and defragmentation/TRIM scripts monthly.

## 2. Repair & Hardware Upgrades
* **Targeted Upgrades over Replacement:** Replace outdated mechanical HDDs with high-speed SATA SSDs and expand RAM to 8GB/16GB. This extends machine usability by 3–5 years at 20% of the cost of new PCs.
* **Modular Repair Policy:** Maintain a spare parts cache (power supplies, RAM sticks, cables) cannibalized from non-repairable units.

## 3. Reuse & Repurposing Strategy
* **Lightweight OS Migration:** When desktops can no longer comfortably run modern Windows builds, re-image them with lightweight Linux distributions (e.g., Lubuntu / Ubuntu LTS).
* **Role Conversion:** Repurpose older hardware as dedicated library catalog terminals, coding lab workstations, or internal DNS/print servers.

## 4. Secure Data Erasure & E-Waste Disposal
* **Data Wiping Standard:** Prior to decommissioning or repurposing, wipe all hard drives using NIST 800-88 compliant tools (e.g., DBAN or `shred`).
* **Certified Recycling:** Partner with certified e-waste recyclers to ensure remaining non-functional materials (batteries, motherboards) do not end up in landfills.
