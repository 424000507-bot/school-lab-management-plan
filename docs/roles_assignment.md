# Team Role Assignments (Group of 8)

| Member | Role | Assigned Task & Focus Area |
| :--- | :--- | :--- |
| **Member 1** | Team Lead & Scenario analysis | Coordinate tasks, review completeness, and explain the laboratory’s IT needs. |
| **Member 2** | Script Developer | Write the PowerShell script and check that all required fields are included. |
| **Member 3** | Script QA & Documentation | Run the script in an authorized Windows environment, capture a genuine screenshot, and document results. |
| **Member 4** | Firewall Design-public services | Propose rules for necessary public access and document their purpose. |
| **Member 5** | Firewall design-administrative access | Propose restricted administration and default-deny rules; review rule order and scope. |
| **Member 6** | Maintenance and Repair Plan | Develop schedules for updates, inspections, repairs, and upgrades. |
| **Member 7** | Reuse, Replacement and E-waste | Set criteria for reuse/replacement and plan secure erasure and responsible disposal. |
| **Member 8** | Synthesis, Video Demo Presentation | Prepare synthesis, organize the report, and coordinate presentation timing 8-10mins. |
